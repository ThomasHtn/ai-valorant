# Frontend

Application Angular qui affiche les rapports de l'API. Organisation du code : `../docs/ARCHITECTURE.md`.

```bash
npm ci
npm start                          # http://localhost:4200, /api redirigé vers l'API sur :8000
npm test -- --watch=false          # tests vitest
npm run build                      # build de production dans dist/
npm run format                     # prettier
```
